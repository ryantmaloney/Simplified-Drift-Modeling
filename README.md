This is the underlying code for simulations in Maloney et al 2024 (https://doi.org/10.7554/eLife.103585.2). Notebooks document examples of analysis, while scripts includes the underlying code for theoretical ecological modeling. More detailed notes, as well as access to raw behavior data (not included on github for space reasons) is available here https://lab.debivort.org/drift-in-individual-preference/
